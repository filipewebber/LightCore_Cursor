# LightCore Cursor

LightCore Cursor is a lightweight World of Warcraft addon that adds a clean ring around your mouse cursor so it is easier to track in combat, raids, dungeons, and busy UI moments.

Designed to stay out of your way:
- Lightweight
- Simple
- Stable

## Features

- Clean cursor ring for better mouse visibility
- Adjustable ring size and thickness
- Class color or custom color
- Optional combat-only display
- Quick access to settings with `/lcc`

## About LightCore

LightCore addons are built to deliver maximum value with minimal overhead:
- Designed around Blizzard’s native API to ensure stability and reduce the risk of Lua errors
- Performance-first approach — no unnecessary processing or visual bloat
- Fully modular and dependency-free, making each addon easy to use, combine or integrate into any UI setup
